## 真实 DeepSeek 与 LangGraph 验收

使用合成约束优化问题进行了三次真实模型生成尝试，保留全部记录，详见[运行记录与复现方法](evidence/README.md)：

| 请求模型与阶段 | 调用次数 | 结果 | 剩余义务 |
| --- | ---: | --- | ---: |
| `deepseek-chat`，提示格式澄清前 | 4 | 格式错误、跳过前提，停滞 | 3 |
| `deepseek-chat`，提示澄清后 | 6 | 正定性通过，后续计算错误；`needs_review`，无报告 | 2 |
| `deepseek-flash`，同一澄清后的提示 | 4 | 引用遗漏被拒绝后修正；`verified_report` | 0 |

最后一次实际通过了 LDL 正定性、原始／对偶 KKT 与全局多项式证书验证，得到最优点 `(1, 3/4, 5/4)` 与最小值 `-73/8`。模型接口报告 7,233 输入 token、10,329 输出 token，合计 17,562；这不是费用或成功率指标。三个归档的候选均使用发布版验证器离线重放，完整的事实、残差、轨迹、证据与停止原因一致。

测试期间只澄清了证书格式与前置步骤说明，没有削弱验证规则或向真实模型注入离线解。真实模式没有备用离线答案。OpenAI 未进行真实联网请求，仅完成 SDK 模拟传输测试；没有外部模型性能基准、生产验收或第三方认证。

## 约束优化

默认三变量二次规划的解为 `(1, 3/4, 5/4)`，最小值 `-73/8`；等式乘子 `1/2`，不等式乘子 `(0,0,0,11/4)`。事件为正定性接受、不可行候选拒绝、原始/对偶证书原子接受、全局平方和恒等式接受；剩余义务数为 `2,2,1,0`。

验证器检查多项式全部系数，不调用提议器的活跃集求解器。测试包括负乘子、互补条件、错驻点、非正定矩阵、错证据、遗漏前提与等价缩放的有效平方和证书。可行但非最优候选被拒绝时不提交原始解，收到实际反馈后可以提出修正证书并完成任务。

## 连续梁桥

默认合成桥梁为 24 m + 30 m 连续线梁，两跨 EI 不同；两组输入组合 × 四种均布活载布置共八个工况。错误的独立简支梁近似因中墩转角不连续被拒绝。

- 中墩最小弯矩：`-225740250/31` N·m，约 −7281.94 kN·m，由 `amplified:both` 控制。
- 两跨最大正弯矩：约 3403.57 / 6241.85 kN·m，分别由左跨与右跨活载布置控制。
- 两个跨中位置的绝对挠度包络：约 4.299 / 10.568 mm；不是全跨最大位移包络。
- 回归测试包含等跨解析基准，以及五组不同几何/刚度/荷载 × 八工况，共 40 个独立虚功柔度法比较；核对支座反力和中墩弯矩。
- v0.4.0 准备期的另一次独立评审使用虚功法核对了 100 组配置 × 八工况，合计 800 个工况，均一致；这些额外检查不计入测试总数。

覆盖错量纲、错作用域、篡改输入、缺前提、漏布载、错误符号与边界条件、零荷载、超限与负支反力。负支反力按双向约束模型报告为抗拔需求，不自动切换成接触/脱空模型。

## 复现

```bash
python -m pip install '.[dev,deepseek,langgraph]'
python -m pytest -q -o pythonpath=.
python -m resimind demo
python -m examples.constrained_optimization
python -m examples.continuous_bridge
python -m examples.langgraph_optimization
python tools/replay_live_audits.py
```

文档图可在额外安装 `matplotlib` 后，用 `PYTHONPATH=src python tools/render_showcase_figures.py` 重建；首页动画使用 Pillow 与 `tools/render_verification_demo.py`。绘图库只用于文档工具，不属于安装包运行时依赖。

仓库提供 [GitHub Actions 配置模板](github-actions-tests.yml)，覆盖 Python 3.10、3.11、3.12、3.13。复制到 `.github/workflows/tests.yml` 后可启用；当前未启用远程 CI，本记录不表示这些远程任务已经运行。

默认候选提议器为离线确定性程序；数学与桥梁的验证和反馈实际执行。只有明确启用真实模型回调才会发起 API 请求。全部桥梁参数、荷载组合与限值为合成输入，均不代表规范条文或真实桥梁记录。
