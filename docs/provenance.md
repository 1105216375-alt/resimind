# 来源与开源范围

这个项目的架构来自「桥梁医生」应用中的两条实现路线：

- `nskernel`：围绕目标、未知项、硬约束和已验证事实组织对话推理。
- `reasoner_kernel`：以 propose → verify → update → rebuild 驱动多步推理。
- 应用中的路线记忆：只在适用条件满足时复用经审核的推理步骤，并要求当前证据再次验证。

本仓库是在这些思想基础上重新整理的独立参考实现，不是原应用的全量镜像，也不承诺 API 兼容。它没有搬入原型中的代数特判、桥梁知识库、模型客户端、界面、业务文件和历史运行记录。

提炼时强化了几条约束：模型不能自报校验通过；验证结论与具体输入绑定；残差由领域适配器基于已提交事实重算；默认不提供任意代码执行；审核记忆不携带自动成立的事实。

原项目中探索过的相位指纹排序、自动知识蒸馏、数学 CAS 和多层语义解析，均不属于首版已实现功能。不将其包装为训练过的语义记忆、通用证明能力或自动学习。

领域独立意味着可以为不同领域实现同一组接口，不意味着一个验证器能处理所有领域。所有示例数据均为本仓库创建的合成数据。
