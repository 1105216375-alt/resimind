# 一般 Lean 目标与定理记忆：小规模开发试验

这是 v0.13.0 之后的本地实验实现，尚不是正式外部评测，也不是长期知识增长的结论。
本轮先检验两件事：现有验证门能否覆盖多项式之外的命题，以及经验证的定理
能否在保存、重载之后，用于结构更复杂的新实例。

## 实际实现

`resimind.integrations.formal` 接受有界、带类型的目标树，包含命题逻辑、自然数
加乘、相等与大小关系。变量在顶层全称量化，蕴含保留条件。只生成固定的
Lean 证明配方；不接受任意 Lean 文本、导入、命令或模型编写的可执行代码。

固定配方包括 `grind`、`omega`、`simp`，以及一个自然数归纳加化简配方。
版本、时间、内存、诊断、公理和编译产物检查复用原有 Lean 4.29.0 验证门。
每个被接受的结果都有绑定目标的源代码摘要和实际编译产物摘要；失败不能
获得成功证明标记。只抑制生成代码中未使用变量和冗余化简参数的外观性提示。

定理记忆最多保存 32 条不可变记录。入库与重载都重新证明；应用时重新编译
记忆中的证明和当前目标。因此，直接构造一个“记忆对象”并不能绕过 Lean。
结构匹配仅提出适用候选，最终是否成立由 Lean 决定。相同变量的多次出现必须
保持一致，不能因为一个模式匹配成功就丢掉原条件。

本轮保存的是已知训练命题的成功证明配方，**尚未实现自主猜想、一般引理抽象、
多引理组合搜索或可学习的 tactic 搜索**。失败目标被记录，后续配方按预设顺序尝试；
这不等于已经实现了根据证明状态动态规划的完整闭环。该模块也不提供长期
存储的事务、恶意文件认证或独立操作系统沙箱。

## 对照协议

- 4 条人工设定的训练命题，依次入库，形成 4 个检查点。
- 24 道不同的开发探针：复合命题上的合取/析取交换、复合自然数项上的加法交换与乘法恒等式。
- 每个检查点比较空记忆、固定第一条定理、不断增长的记忆，共 288 次任务求解。
- 三组使用相同的自动化配方、每题最多 6 次编译调用、每次编译最多 10 秒。
- 同题的三组运行顺序使用固定随机种子打乱；模型调用均为 0。
- 每轮先验证入库，再保存重载；记录训练与重载成本。评估不会把探针答案写回记忆。
- 4 个错误命题作为反向控制，另有测试覆盖伪造记忆、重复 JSON 字段和输入注入。

24 道探针在各轮重复使用，训练命题及其数学概念由人设定，且 Lean 自身含有
成熟的算术与逻辑工具。因此这是一组实现和消融探针，不能称作独立测试集、
跨领域泛化、千题长期试验或对前沿系统的公平排名。编译调用数也不等于
总证明工作量：记忆组在一次编译中会重验多条定理，墙钟成本必须一起看。

| 1 / 1 | 24/24 | 24/24 | 24/24 | 6 |
| 2 / 2 | 24/24 | 24/24 | 24/24 | 12 |
| 3 / 3 | 24/24 | 24/24 | 24/24 | 18 |
| 4 / 4 | 24/24 | 24/24 | 24/24 | 24 |

最终一轮的累计求解时间分别是空记忆 **16.03 s**、固定记忆 **16.59 s**、
增长记忆 **16.43 s**。每组都是 24 次编译调用。增长组四轮另外花费
**7.32 s 入库验证、7.12 s 保存后的重载验证**；这些费用未混入求解时间，
也不能在总体费用比较时省略。所有组均未调用模型。四个错误命题均保持未决。

空记忆组的任务全部由第一种自动化配方 `grind` 完成。增加定理记忆确实使
新结构实例转向了直接定理应用，但**完成率增益为 0，没有稳定的省时证据**。
不应通过限制对照组工具或事后挑选有利任务，把这个结果改写成性能优势。
单机单次时间差只作描述，不能解释为显著提升或显著退化。

本轮证明的是：多项式之外的带类型目标可通过实际 Lean 内核核验；一个普遍
成立的定理能在复合实例上重用；增长、冻结与重载流程可执行。它没有证明
自主发现新定理、长期任务收益或对外部强 Agent 的优势。正式实验需要能够
区分强自动化工具与知识复用的预先冻结任务，并单独报告全部训练费用。

## 复现

需要已安装的 Lean 4.29.0；不会自动下载工具链，也不调用模型 API。

```bash
PYTHONPATH=src:. python -m benchmarks.run_formal_memory_pilot \
  --output /absolute/path/outside/repository/new-formal-pilot
python -m pytest tests/test_formal.py tests/test_lean.py -q
```

运行前写出代码摘要、训练命题、评估目标和资源限制；运行后核对源代码没有变化。
目标、尝试、失败和成本保存在仓库外的原始记录中。正式外部评测仍需单独固定
数据集及其许可证、Lean/Mathlib 版本、模型快照、预算与基线实现。
